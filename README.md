# CoinPulse

CoinPulse is a modern cryptocurrency tracking web application built with Next.js and React. It allows users to discover top cryptocurrencies, monitor their performance, explore market categories, and access detailed pages for each asset.

## Features

- Overview of popular cryptocurrencies
- Trending coins and category exploration
- Detailed pages for each cryptocurrency with key information
- Price charts and data tables
- Cryptocurrency conversion between different assets
- Modern, responsive user interface

## Tech Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- shadcn/ui
- WebSocket
- Lightweight Charts for data visualization

## Installation

```bash
pnpm install
```

## Getting Started

```bash
pnpm dev
```

Then open [http://localhost:3000](http://localhost:3000) in your browser.

## Project Structure

- `app/` – Application pages and routes
- `components/` – Reusable UI components
- `hooks/` – Custom React hooks
- `lib/` – Business logic and integrations
- `utils/` – Constants and utility functions

## About

CoinPulse was designed to provide a simple and intuitive way to track the cryptocurrency market in real time through a clean, visual interface.
